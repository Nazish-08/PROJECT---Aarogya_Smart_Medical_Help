# 🏥 Aarogya Smart Medical Help

Aarogya Smart Medical Help is an AI based medical assistance system developed to provide basic health related guidance based on user reported symptoms.

The system analyzes selected symptoms and provides possible health related suggestions along with doctor recommendations.

This project was developed as an academic project to demonstrate the use of Python, AI based logic, machine learning concepts, HTML, CSS, and JavaScript in the healthcare domain.

> ⚠️ **Disclaimer:** This project is developed for educational purposes only. It is not a medical diagnostic system and should not replace professional medical advice.

---

## 🚀 How to Run

### 1. Clone the Repository

    git clone https://github.com/Nazish-08/PROJECT---Aarogya_Smart_Medical_Help.git

### 2. Navigate to the Project Directory

    cd PROJECT---Aarogya_Smart_Medical_Help

### 3. Create a Virtual Environment

    python -m venv venv

### 4. Activate the Virtual Environment

#### Windows

    venv\Scripts\activate

#### Linux / macOS

    source venv/bin/activate

### 5. Install Dependencies

    pip install -r requirements.txt

### 6. Run the Application

    python app.py

### 7. Open in Browser

Open the local host address displayed in the terminal.

Example:

    http://127.0.0.1:5000

> Refer to `How to run.txt` for the exact project specific execution instructions.
